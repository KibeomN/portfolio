Problem

문제 정의

수업이 끝난 뒤, 자기 전, 아침에 일어나서. 회원 일정 확인과 변경 요청을 카카오톡과 문자로 하루에도 몇 번씩 챙겨야 했습니다.

퍼스널 트레이너로 3년간 일하며 회원 관리를 메신저로 했습니다. 일정 변경, 남은 회차, 운동 기록이 대화 속에 흩어져 있어 누락이 생기기 쉬웠고, 업무 연락과 사적 연락의 경계도 흐려졌습니다.

  • 일정 — 변경·취소가 대화로만 오가서 최신 시간표가 어디에도 없음
  • 회차 — 남은 횟수를 트레이너가 따로 계산하고 회원은 확인할 방법이 없음
  • 기록 — 운동 내용이 트레이너 메모에만 남아 회원과 공유되지 않음
Research

경쟁 앱 리뷰 분석

기존 PT 관리 앱의 스토어 리뷰를 모아 사용자가 칭찬하는 점과 불만을 5개씩 정리하고, 기획 방향의 근거로 삼았습니다.

사용자가 좋아한 점

  • 무료로 시작할 수 있음
  • 수업 전 운동일지 공유로 회원 만족
  • 몸 변화 시각화가 재등록에 도움
  • 쉬운 사용성
  • 회차 계산·수업 전 알림 자동화

사용자가 불만인 점

  • 짧은 무료 기간 뒤 구독 강제
  • 로딩 지연·먹통 등 안정성 문제
  • 기록 방식이 유연하지 않음
  • 캘린더 기능 미흡
  • 카톡 사적 연락으로 인한 부담

결론 — 불만의 핵심은 유료 압박과 안정성, 칭찬의 핵심은 일지 공유였습니다. 수업 사이 짧은 틈에 쓰는 앱이라 안정성을 QA 최우선 기준으로 정했습니다.

결정PT 특화로 출발, 종목 확장은 나중에
근거

처음부터 골프·수영까지 넓히면 데이터가 모이지 않습니다. PT로 좁혀 검증한 뒤 레슨 관리 플랫폼으로 넓히는 순서로 로드맵을 짰습니다.

결정과한 기능은 지우지 않고 숨기기
근거

회차 보정, 보강 기록, 미디어 동의 같은 심화 기능은 플래그 하나로 첫 화면에서만 숨겼습니다. 출시 화면은 단순하게, 데이터와 기능은 그대로 유지합니다.

결정회원 전용 인앱 채팅
근거

경쟁 앱 리뷰와 제 경험 모두에서 카톡 사적 연락이 부담으로 나왔습니다. 업무 소통을 앱 안으로 분리했습니다.

결정핵심 지표는 노쇼율
근거

재등록률은 도입 전 기준값이 없어 증명할 수 없습니다. 노쇼율은 수업 상태 데이터로 알림 전후를 앱 안에서 바로 비교할 수 있어, 과장 없이 쓸 수 있는 지표로 골랐습니다.

QA · Ops

QA와 운영 준비

전체 파일을 대상으로 정적 점검을 여러 차례 돌리고, 실기기 점검표를 만들어 출시 전 결함을 정리했습니다. 발견한 문제는 원인과 영향 범위를 확인한 뒤 수정했습니다.

심각도발견한 문제조치
높음초대 수락 시 회차 이력이 남지 않아 잔여 회차와 이력 합계가 불일치가입 이력 기록 추가, 기존 데이터 영향 없음 확인
높음알림 로그 테이블에 접근 정책 누락클라이언트 접근 차단, 서버 전용으로 변경
높음일지 코멘트 기능에 비로그인 사용자 권한이 열려 있음로그인 사용자 전용으로 권한 회수
보통잔여 회차 부족 알림 기준이 회원·트레이너 모두 10회로 동작회원 5회 / 트레이너 10회로 분리
보통변경된 수업이 미처리 수업 집계에서 누락조회 조건 보완
